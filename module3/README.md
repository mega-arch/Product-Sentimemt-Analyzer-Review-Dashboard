
# Module 3 – Sentiment Analysis Engine (VADER + TextBlob)

This module performs sentiment classification using two rule-based NLP models:
- VADER
- TextBlob

## Files
- `predict.py` — Predicts sentiment using both models
- `vader_model.py` — VADER sentiment function
- `textblob_model.py` — TextBlob sentiment function
- `train.py` — Runs model on cleaned dataset (Module 2)
- `utils.py` — Shared cleaning utilities
- `__init__.py` — Package initializer
